# جُمْلَتِي 🏪

> تطبيق عراقي متكامل يربط السوبرماركت بتجار الجملة ومندوبي التوصيل

## 🎯 عن المشروع

**جُمْلَتِي** — نظام B2B عراقي للطلبات بين:
- 🏪 السوبرماركت (Retailer) — يطلب من تجار الجملة
- 📦 تجار الجملة (Supplier) — يعرضون منتجاتهم
- 🚚 مندوب التوصيل (Delivery) — يوصّل الطلبات
- 🛡️ الإدارة (Admin) — تدير النظام

## ✨ الميزات الرئيسية

### للأدوار الأربعة
- تسجيل دخول + توجيه حسب الدور
- دورة طلب كاملة من الإنشاء للتسليم
- إشعارات فورية (Push + Realtime)
- تتبع الطلب مع Timeline

### للمدير
- تقارير متقدمة (KPIs + رسوم + نمو)
- 21 Feature Flag للتحكم بالميزات
- إدارة مالية شاملة (عمولات + مستحقات + دفعات)
- إدارة المستخدمين + RLS
- كوبونات + مرتجعات + دعم فني
- إدارة طرق الدفع

### للسوبرماركت
- تصفح تجار الجملة + منتجاتهم
- قائمة الرغبات
- نقاط ولاء
- كوبونات الخصم
- فواتير + طباعة

### لتاجر الجملة
- إدارة المنتجات + المخزون
- إدارة الطلبات الواردة
- أرباح + عمولات
- العروض الترويجية

### للمندوب
- مهام التوصيل
- تتبع الأرباح + المستحقات
- سجل المهام

## 🚀 التشغيل

### 1) المتطلبات
- Node.js v20+
- npm أو pnpm

### 2) التثبيت
npm install

### 3) متغيرات البيئة

انشئ .env.local واضف:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- NEXT_PUBLIC_VAPID_PUBLIC_KEY
- VAPID_PRIVATE_KEY
- VAPID_SUBJECT

### 4) التشغيل
npm run dev

افتح http://localhost:3001
