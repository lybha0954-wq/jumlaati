# البيانات التجريبية — جُمْلَتِي

> ملفات SQL جاهزة للاستخدام من **Supabase SQL Editor**

## 📂 الملفات

| الملف | الغرض | متى يُستخدم |
|-------|-------|-------------|
| `seed-demo.sql` | إضافة بيانات تجريبية | للاختبار |
| `clean-demo.sql` | حذف كل DEMO | قبل الإطلاق |

## 🎯 الاستخدام

### 1) إضافة بيانات تجريبية
1. افتح **Supabase SQL Editor**
2. املح محتوى `seed-demo.sql`
3. الصق → Run
4. **النتيجة:** 3 تصنيفات + 9 منتجات + 6 طلبات

### 2) حذف البيانات التجريبية
1. افتح **Supabase SQL Editor**
2. املح محتوى `clean-demo.sql`
3. الصق → Run
4. **النتيجة:** كل DEMO محذوف

## 🏷️ العلامات المميزة

البيانات التجريبية تحمل علامات واضحة:
- **الطلبات:** `order_number LIKE 'DEMO-%'`
- **المنتجات:** `name LIKE '[DEMO]%'`
- **الحسابات:** `email LIKE '%@demo.test'`

## ⚠️ ملاحظات

- البيانات تُنشأ لحسابات موجودة (`tester.one`, `tester.two`)
- الطلبات توزَّع على 4 حالات (pending/accepted/shipped/delivered)
- الحذف **آمن** — لا يمس بيانات حقيقية
